Онлайн-кинотеатр с рекомендательной системой

О проекте

Система анализирует предпочтения пользователей онлайн-кинотеатра и формирует персональные рекомендации фильмов на основе жанров, оценок и истории просмотров.

Основные возможности

- Просмотр каталога и информации о фильмах.
- Выставление оценок фильмам.
- Сохранение истории просмотров и процента досмотра.
- Получение персональных рекомендаций.
- Управление каталогом фильмов для менеджера контента.

Архитектура

Приложение использует трёхуровневую клиент-серверную архитектуру:

- Клиентский уровень: React SPA.
- Серверный уровень: NestJS, Controller, Service, Auth, Guards и ORM.
- Уровень данных: PostgreSQL.

Взаимодействие между frontend и backend осуществляется через REST API по HTTPS с использованием JSON.

Роли пользователей

- Viewer — просмотр фильмов, выставление оценок и получение рекомендаций.
- Content Manager — управление каталогом фильмов.

Технологии

React, NestJS, PostgreSQL, ORM, REST API, HTTPS, JSON.
