Варианты использования системы

1. Просмотр каталога фильмов

Актор: Viewer.

Основной сценарий:

1. Пользователь открывает каталог.
2. Frontend отправляет запрос серверу.
3. Сервер получает список фильмов из базы данных.
4. Пользователь видит каталог фильмов.

Результат: пользователь получает доступ к каталогу.

2. Выставление оценки фильму

Актор: Viewer.

Основной сценарий:

1. Пользователь открывает страницу фильма.
2. Выбирает оценку и отправляет её.
3. Сервер проверяет авторизацию и корректность данных.
4. Оценка сохраняется в базе данных.
5. Пользователь получает подтверждение.

Результат: оценка сохранена.

3. Получение рекомендаций

Актор: Viewer.

Основной сценарий:

1. Пользователь открывает раздел рекомендаций.
2. Сервер получает данные о предпочтениях и истории просмотров.
3. Система формирует список подходящих фильмов.
4. Рекомендации отображаются пользователю.

Результат: пользователь получает персональный список фильмов.

4. Управление каталогом

Актор: Content Manager.

Основной сценарий:

1. Менеджер входит в систему.
2. Выбирает добавление или редактирование фильма.
3. Сервер проверяет права доступа.
4. Изменения сохраняются в базе данных.
5. Менеджер получает результат операции.

Результат: каталог обновлён.
