Риски проекта и меры снижения

1. Утечка персональных данных

Риск: злоумышленник может получить доступ к данным пользователей.

Меры снижения:

- Хранить пароли только в виде хешей.
- Использовать HTTPS.
- Проверять права доступа к защищённым операциям.

2. Несанкционированное изменение каталога

Риск: обычный пользователь может попытаться добавить или изменить фильм.

Меры снижения:

- Использовать аутентификацию и Guards.
- Разграничивать права пользователей по ролям (RBAC).
- Проверять права на сервере, а не только в интерфейсе.

3. Потеря или повреждение данных

Риск: сбой базы данных может привести к потере оценок и истории просмотров.

Меры снижения:

- Регулярно создавать резервные копии.
- Использовать ограничения целостности данных.
- Контролировать ошибки при выполнении операций.

4. Нерелевантные рекомендации

Риск: система может предлагать фильмы, которые не соответствуют интересам пользователя.

Меры снижения:

- Учитывать жанры, оценки и историю просмотров.
- Регулярно проверять качество рекомендаций.
- Предусмотреть рекомендации популярных фильмов для новых пользователей.
